> 🏠 **Este é o último curso da trilha e é para fazer em casa:** precisa do **Git e do VS Code instalados** no seu computador. Fez os outros dois (Minha primeira entrega e Trabalho em equipe)? Aqui você completa a trilha! 🏆

## ✅ Antes de começar

- **Git instalado:** no terminal do VS Code, `git --version` mostra a versão
- **VS Code** instalado
- **Git configurado** com o seu nome e com o **mesmo e-mail da sua conta do GitHub**:

```bash
git config --global user.name "Seu Nome"
git config --global user.email "email-da-sua-conta@exemplo.com"
```

Dúvidas? Veja o módulo 4 do [Curso de GitHub](https://maristelaoliveira.github.io/curso-github/#m4).

## 🚀 Como começar

1. Lá em cima, clique no botão verde **Use this template** → **Create a new repository**
2. Em **Repository name**, escreva `pratica-git-vscode`
3. Deixe marcado **Public** e clique em **Create repository**
4. Espere uns 20 segundos e abra a aba **Issues** do **seu** repositório novo: a sua primeira tarefa vai estar lá! 📬
